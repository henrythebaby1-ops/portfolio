# Clawd Street

This project is an Electron app.

## Run

```bash
npm install
npm start
```

## Package As An App

```bash
npm run pack
```

Create a distributable build with:

```bash
npm run dist
```

## Change App Name

Edit these files:

- `app-config.json`
- `package.json`

## Change App Icon

Replace these files:

- `build/icon.png`
- `build/icon.icns`

If you want a Windows app icon later, add `build/icon.ico`.
