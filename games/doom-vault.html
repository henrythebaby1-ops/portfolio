    Keep every version of your files.

    Connect a file or a folder once. Each time you press Update files, Doom Vault reads the latest copy from disk, shows it here, and saves the previous one to the history so you can download it later.

    1. Connect a file such as room.html, or the whole folder.
    2. Edit and save the file in any editor.
    3. Press Update files. Changed files get a new version in the timeline.

    This browser can't re-read files on its own. Use Chrome, Edge, Arc or Brave for one-click updates. Here, Update files asks you to pick the files again.
