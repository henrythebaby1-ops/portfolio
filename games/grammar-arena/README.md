# Grammar Arena

Grammar Arena is a lightweight browser game focused on grammar practice, with bonus learning sets for English, math, and history.

## Features

- Grammar-first question bank with sentence structure, punctuation, capitalization, and parts of speech.
- Extra English, math, and history rounds.
- Three game modes: Quest, Blitz, and pass-and-play PvP Duel.
- Local achievements and streak-based scoring.
- Automated tests for deck creation, scoring, and turn flow.
