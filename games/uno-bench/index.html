How Uno Bench works

    
Uno Bench simulates an Arduino Uno (ATmega328P, 16 MHz) and the parts wired to it, entirely in your browser.

    
Two ways to run code

    
    
      
  • Arduino C++ runs your sketch instantly through a built-in interpreter. It covers the everyday Arduino API: pinMode, digitalWrite, analogRead, analogWrite, millis, delay, tone, Serial, attachInterrupt, plus the Servo, LiquidCrystal / LiquidCrystal_I2C and Adafruit_NeoPixel libraries.
    • 
      
  • HEX firmware runs real compiled machine code on a cycle-accurate AVR core (avr8js), with timers, GPIO, ADC and USART. In the Arduino IDE use Sketch → Export Compiled Binary, then open the .ino.hex file (not the one ending in with_bootloader).
    • 
    

    
Interpreter limits

    
    
      
  • Integer division only truncates when the result is stored in an int/long variable. millis() / 1000 passed straight to print shows decimals.
    • 
      
  • Pointers, struct/class definitions, templates and static locals are not supported. Use HEX mode for those sketches.
    • 
      
  • LCD and NeoPixel parts respond in Arduino C++ mode only. LEDs, buttons, potentiometers, servos, buzzers and 7-segment displays work in both modes.
    • 
    

    
Wiring

    
Click a part to choose which Uno pin each of its terminals connects to. Ground and 5 V connections are implied. Buttons connect their pin to GND when pressed (use INPUT_PULLUP), or to 5 V if you change it in the part settings. Your circuit and code are saved in this browser.

    
Shortcuts

    
Ctrl/⌘ + Enter runs the program. Delete removes the selected part. The red button on the board restarts it.
