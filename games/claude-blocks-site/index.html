Install help

The apps aren’t from an app store yet, so your device may ask you to confirm the first time.

Mac (.dmg)
  1. Open ClaudeBlocks-mac.dmg and drag Claude Blocks into Applications.
  2. The first time, right-click (or Control-click) the app and choose Open, then Open again. If it’s still blocked: System Settings → Privacy & Security → Open Anyway.
  3. Works on Apple Silicon and Intel Macs.
Windows (.exe)
  1. Run ClaudeBlocks-windows-setup.exe.
  2. If Windows SmartScreen appears, click More info → Run anyway.
  3. Follow the installer, then start Claude Blocks from the Start menu.
Linux (.AppImage)
  1. Make it runnable: chmod +x ClaudeBlocks-linux.AppImage
  2. Run it: ./ClaudeBlocks-linux.AppImage (or double-click it).
  3. If it doesn’t start, install FUSE 2 (for example sudo apt install libfuse2).
Android phones & tablets (.apk)
  1. Download ClaudeBlocks-android.apk on your phone.
  2. Open it. If asked, allow your browser or Files app to install unknown apps.
  3. Tap Install.
Chromebook (.apk)
  1. Make sure Google Play Store is turned on in Settings → Apps.
  2. Chromebooks only install downloaded Android apps when Android app development (ADB debugging) is on: Settings → Advanced → Developers → Linux development environment → Develop Android apps.
  3. Then open the Linux terminal and run adb install ClaudeBlocks-android.apk. Or simply use the web version.
iPhone, iPad & everything else (web)
  1. Open the web version in Safari, Chrome, Edge or Firefox.
  2. On iPhone or iPad, tap Share → Add to Home Screen to use it like an app.
  3. The web version is for coding with blocks, Python and HTML. It doesn’t turn projects into HTML/CSS/JS and only uses the Raspberry Pi emulator.
Raspberry Pi bridge

To control a real Raspberry Pi 5 from the full app, download pi-bridge.py, copy it to your Pi and run python3 pi-bridge.py. Then connect from the 🍓 Pi 5 tab.
